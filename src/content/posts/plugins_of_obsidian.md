使用Obsidian也有一年多了，稍微整理一下现在高频率使用的一些插件，顺便就当作推荐了。但是我还不算特别深度使用，一年多也只有将近400份笔记。

话不多说，即刻开波！

## Components （闭源付费）

首先是目前还没有上架官方商城的 [Components](https://wxycbt0cjk.feishu.cn/wiki/GczJwNXb1iNbookQkbscMXOhnO4)，通称CPs。现在永久授权是 98¥，我觉得是物超所值。这款插件宗旨就是用一个一个组件满足客户需求，避免繁杂的脚本编辑和工作流设立。

用 CPs 可以很方便地进行信息整合和展示，在我的使用中已经完全替代了 dataview 的功能了。而最近在更新的表单→Flow功能，CPs 则可以更方便地运行脚本和操作流，方便信息录入，打通信息从入到出的全流程自动化。

![CPs 主页示例](https://image.linglilongyi.com/2025/04/components主页.avif "CPs 做的主页真好看")

而且交流反馈的群里有许多 Obsidian 的玩家，会提供很多有意思的技巧和干货，我也学习了许多。

## Templater

基本上所有OB玩家都会用到的三个插件，Dataview、Templater、Quickadd，人称OB三巨头。上文所说的 CPS 也正在希望通过新功能替代 TP 和 QA。但对我来说，Templater 还有一个极好的功能是可以给文件夹添加默认模板，意味着我只需在文件夹里新增文档，自动会应用模板。

现在我使用最多的场景就是用来写博客。

## Hover Editor

增强OB自身的页面预览功能，将预览的弹出框变成完整功能的编辑器。可以不脱离当前文件进行特定文件的查看或编辑，有利于保持思路的同时方便各种操作。

## Hot key for specific files

可以给文件加上快捷键，并且支持时间变量，可以快速打开今天的日记、主页还有特定的文件。现在还支持配合 Hover Editor 以弹出框打开特定文件。

## Modal Opener

以模态框打开文件，更美观地暂时打开文档的方式。

## MySnippets && Style Setting

这两个插件就是管理OB 样式的最强组合。现在自定义做得比较好的主题和插件都会注册Style Setting 选项，不需要手动改 CSS 即可更改样式，而自己写或抄下来的 CSS 片段则用 MySnippets 进行管理。

## Image Converter

超级好用的图片管理插件，可以快速实现图片格式转换、剪裁变换、重命名、移动存放位置。支持在复制到OB时进行转换。

## Image Uploader for note

将单个笔记内所有图片上传到图床中并替换原文链接。很多其它的插件都是全库上传或者加入ob时自动上传的，但是对库里大部分图片来说并没有上传的需求，只有在写博客的时候需要。与 Image Converter 一起用可以快速压缩图片并上传图床。

## Recent Notes

之前有个插件叫 Recent Files，好多人在用，但只要打开一下文件就会在记录中出现，而进行同步的时候更是会引起大批量的记录更新。实际上，在我个人使用场景里，我更关注我最近编辑的笔记，而 Recent Notes 完全贴合我的需求，并拥有不俗的颜值。
